# What is Home Networkᵀ?

Home Networkᵀ is a Trisul Network Analytics concept used to define and identify trusted internal network environments within monitored infrastructure.

It helps organize traffic visibility by separating internal network traffic from external or internet-facing communication.

By defining a Home Networkᵀ, Trisul can better understand:
- internal traffic behavior
- inbound and outbound communication
- east-west traffic movement
- local application activity
- trusted network boundaries
- traffic direction roles

This improves operational context and makes traffic analysis easier and more meaningful.

## How Home Networkᵀ Works

In most environments, organizations monitor traffic flowing between:
- internal systems
- branch offices
- cloud services
- remote users
- internet destinations

Without defined network roles, traffic analysis can become confusing because the monitoring platform may not know:
- which IPs belong to the organization
- which systems are internal
- which traffic is external

Home Networkᵀ solves this by allowing teams to define trusted internal IP ranges or network segments.

For example:

1. Internal IP ranges are configured as Home Networkᵀ
2. Trisul identifies traffic originating from trusted systems
3. Traffic direction and communication roles become clearer
4. Dashboards and analytics use the internal context for visibility

This improves:
- traffic classification
- bandwidth analysis
- security monitoring
- application visibility
- traffic investigation workflows

## Why Home Networkᵀ Matters

Without clear internal network definitions, monitoring platforms may struggle to:
- distinguish inbound vs outbound traffic
- classify local communication correctly
- identify internal traffic movement
- analyze subscriber behavior accurately
- prioritize operational visibility

Home Networkᵀ helps teams:
- improve operational context
- simplify traffic investigation
- organize visibility workflows
- identify internal systems quickly
- analyze local traffic behavior
- improve reporting accuracy

It is especially useful in:
- enterprise networks
- ISP environments
- branch infrastructures
- cloud deployments
- hybrid networks
- SOC operations

## Common Operational Use Cases

### Internal Traffic Visibility

Monitor communication between internal systems and applications.

### East-West Traffic Analysis

Analyze lateral traffic movement across trusted environments.

### Security Monitoring

Identify suspicious outbound or inbound communication.

### Bandwidth Monitoring

Separate local traffic from internet-bound traffic.

### Application Analytics

Analyze how internal applications communicate across the network.

## Home Networkᵀ vs External Network Visibility

| Feature | Home Networkᵀ | External Traffic Visibility |
|---|---|---|
| Traffic Role | Trusted internal traffic | External communication |
| Visibility Focus | Internal systems and users | Internet-facing traffic |
| Traffic Direction Context | Clear | Less contextual |
| Operational Relevance | High for local analysis | High for perimeter analysis |
| Security Perspective | Internal behavior | External threats |

Home Networkᵀ improves visibility into trusted internal traffic environments.
