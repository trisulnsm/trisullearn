# What is Top-K Analyticsᵀ?

Top-K Analyticsᵀ is a Trisul Network Analytics capability used to identify and analyze the highest-ranking traffic entities within large-scale network environments.

The “K” represents the top number of entities being tracked, such as:
- top 10 hosts
- top 100 applications
- top 1000 flows
- highest bandwidth consumers
- busiest interfaces
- most active ASNs

Top-K Analyticsᵀ helps organizations define traffic prioritization and visibility roles by focusing on the most operationally significant traffic behavior instead of analyzing every entity equally.

It is especially useful for:
- bandwidth monitoring
- traffic investigation
- anomaly detection
- application visibility
- ISP analytics
- operational troubleshooting

## **How Top-K Analyticsᵀ Works**

Trisul continuously analyzes traffic visibility data from:
- flow records
- packet analytics
- application metadata
- protocol activity
- ASN visibility
- traffic counters

The Top-K Analyticsᵀ engine:
1. ranks entities by traffic or activity metrics
2. continuously updates the rankings
3. highlights the highest-impact traffic behavior
4. enables deeper operational investigation

A typical workflow looks like this:

Traffic Data → Ranking Engine → Top-K Analyticsᵀ → Investigation

Entities may be ranked by:

- bandwidth usage
- packet volume
- flow count
- connection count
- application activity
- protocol usage
- subscriber traffic
- ASN traffic

For example:

- WAN congestion occurs
- Top-K Analyticsᵀ identifies the top bandwidth-consuming applications
- Analysts investigate and optimize traffic policies

- identify important traffic quickly
- troubleshoot congestion efficiently

Top-K Analyticsᵀ helps teams:

- focus on the most impactful traffic behavior
- improve operational awareness
- identify high-bandwidth consumers
- investigate suspicious activity faster
- optimize bandwidth usage
- strengthen troubleshooting workflows

It is especially important in:

- ISP infrastructures
- enterprise WANs
- cloud environments
- telecom networks
- data centers
- SOC operations

Humans eventually realized analyzing every packet equally was madness, so they invented systems that basically say: “show me the biggest troublemakers first.” Finally, some practical thinking.

## **FAQ**

### What is Top-K Analyticsᵀ?

Top-K Analyticsᵀ is a Trisul capability that identifies and ranks the most significant traffic entities based on traffic activity or operational metrics.

### What does “K” mean in Top-K Analyticsᵀ?

“K” represents the number of highest-ranking entities being tracked, such as the top 10 or top 100 traffic consumers.

### Why is Top-K Analyticsᵀ important?

It helps organizations focus on the most operationally important traffic behavior for troubleshooting and analysis.

### What can Top-K Analyticsᵀ analyze?

It can analyze hosts, applications, ASNs, protocols, flows, interfaces, subscribers, and bandwidth consumers.

### How does Top-K Analyticsᵀ help security operations?

It helps identify suspicious high-volume communication and abnormal traffic concentration quickly.

### Is Top-K Analyticsᵀ useful for ISPs?

Yes. ISPs use it to monitor top subscribers, backbone traffic, peering activity, and application usage trends.
