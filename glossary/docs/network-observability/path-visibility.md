# What is Path Visibility?

Path visibility is the ability to see the routes, hops, and performance characteristics that traffic takes between a source and destination.

It helps identify where delays, failures, or bottlenecks occur.

Because traffic doesn’t teleport.

Sadly.

---

## In Simple Terms

Imagine sending a package.

You want to know:

- where it is  
- where it stopped  
- where it got delayed  

That is path visibility.

Network traffic works the same way.

It moves through multiple hops.

Path visibility tracks the journey.

Because the journey is often the problem.

Not the destination.

---

## Technical Explanation

Path visibility provides operational insight into the network routes traffic follows across internal and external networks.

It typically tracks:

- hop-by-hop paths  
- latency per hop  
- packet loss per segment  
- routing changes  
- path stability  

Path visibility is important for:

- internet performance  
- WAN monitoring  
- cloud application performance  
- troubleshooting  

Routes change.

Performance changes with them.

Predictably.

---

## How Path Visibility Works

1. Traffic paths are discovered  
2. Hops are identified  
3. Path performance is measured  
4. Route changes are tracked  
5. Bottlenecks and failures are identified  

Traffic moves.

Visibility follows.

That’s the goal.

---

## What Does Path Visibility Analyze?

Path visibility analyzes:

| Path Signal | Description |
|---|---|
| Hops | Intermediate devices along the path |
| Latency | Delay at each hop |
| Packet Loss | Loss between hops |
| Route Changes | Path changes over time |
| Stability | Consistency of the route |
| Congestion Points | Performance bottlenecks |

Every hop matters.

Some more than others.

Usually the broken one.
