# What is Query-Based Traffic Investigation?

Query-Based Traffic Investigation is the process of searching, filtering, and analyzing network traffic data using specific queries to investigate communication behavior, troubleshoot issues, and identify suspicious activity.

Instead of manually reviewing massive amounts of traffic data, analysts use structured queries to quickly isolate relevant traffic patterns and events.

Query-based investigation helps organizations define investigative roles by enabling targeted visibility into:
- IP communication
- application activity
- protocol behavior
- suspicious sessions
- bandwidth spikes
- historical traffic
- security anomalies

It is widely used for:
- troubleshooting
- network forensics
- security investigations
- incident response
- application analysis
- traffic correlation

## How Query-Based Traffic Investigation Works

Monitoring platforms collect visibility data from:
- flow records
- packet captures
- DNS logs
- application analytics
- traffic metadata
- security telemetry

Analysts then perform searches using filters such as:
- IP addresses
- ports
- protocols
- applications
- ASNs
- timestamps
- traffic direction
- bandwidth thresholds
