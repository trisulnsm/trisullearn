# What is Root Cause Analysis?

Root cause analysis (RCA) is the process of identifying the underlying cause of an incident or problem instead of only addressing its visible symptoms.

It improves troubleshooting, incident response, and long-term reliability.

Because fixing symptoms is temporary.

Causes return.

Like bad habits.

---

## In Simple Terms

Imagine your car stops working.

The symptom is:

- it won’t start  

The root cause might be:

- dead battery  
- fuel issue  
- starter failure  

Fixing the symptom means nothing.

Fixing the cause solves the problem.

Networks are no different.

Just louder.

---

## Technical Explanation

Root cause analysis uses operational data, telemetry, and investigative methods to identify the original source of failures or performance issues.

It commonly analyzes:

- traffic flows  
- logs  
- metrics  
- traces  
- events  
- dependency chains  

Root cause analysis helps identify:

- configuration errors  
- infrastructure failures  
- traffic bottlenecks  
- security incidents  
- service dependencies  

Symptoms are evidence.

Causes are truth.

That’s the job.

---

## How Root Cause Analysis Works

1. An issue is detected  
2. Symptoms are identified  
3. Related telemetry is collected  
4. Events and dependencies are correlated  
5. The underlying cause is isolated  

Detection begins the process.

Understanding ends it.

Hopefully.
