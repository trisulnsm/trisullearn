# What is network monitoring?

Network monitoring is the process of observing network devices, links, and traffic to detect issues, measure performance, and maintain service health.

---

## How network monitoring works

Network monitoring collects telemetry from routers, switches, firewalls, links, and traffic sources. The data may include counters, logs, flows, packets, and health status.

The goal is to understand whether the network is operating normally. If traffic changes, loss increases, or a device fails, the monitoring system should show it quickly.

---

## Network monitoring in operations

Network monitoring is one of the core tasks of the NOC. It helps teams detect outages, congestion, and abnormal behavior before users are badly affected.

It also supports routine maintenance and capacity planning. By watching trends over time, operators can see which links or devices are becoming stressed.

---

## Common network monitoring signals

| Signal | Meaning |
|---|---|
| Device status | Up or down |
| Interface utilization | Link load |
| Packet loss | Traffic is being dropped |
| Latency | Delay in delivery |
| Traffic trends | Growth or change over time |

---

## What makes network monitoring useful

Monitoring is most useful when it covers both infrastructure and traffic. A device may be up, but the traffic path may still be congested or broken.

Good monitoring also requires baselines. A spike only matters if you know what normal looks like.

## Frequently asked questions

### What is network monitoring?

Network monitoring is the process of observing network devices, links, and traffic to detect issues, measure performance, and maintain service health.

### What does network monitoring track?

Network monitoring can track device status, interface utilization, packet loss, latency, throughput, logs, and traffic trends depending on the tools in use.

### Why is network monitoring important?

Network monitoring is important because it helps teams detect outages, congestion, and unusual behavior before they become major problems.

### How is network monitoring used in operations?

Network monitoring is used by NOC and operations teams to keep services healthy, troubleshoot issues, and plan for capacity growth.
