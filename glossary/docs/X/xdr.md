# What is XDR?

XDR, or Extended Detection and Response, is a security approach that collects and correlates telemetry across endpoints, networks, identities, and cloud systems.

---

## How XDR works

XDR gathers signals from multiple layers of the environment and links them together into a single detection view. That makes it easier to see related activity across tools and systems.

The goal is faster and better detection. A weak signal in one place may become meaningful when combined with signals from another.

---

## XDR in operations

XDR is used by security teams to improve detection and investigation across domains. It helps connect endpoint, network, identity, and cloud behavior.

It is especially useful when attacks cross several parts of the environment. Correlation makes the full picture easier to see.

---

## Common XDR inputs

| Input | Meaning |
|---|---|
| Endpoint telemetry | Device behavior |
| Network telemetry | Traffic activity |
| Identity data | User and login signals |
| Cloud data | Cloud service events |

---

## What makes XDR useful

XDR is useful because modern attacks often span multiple systems. Correlation across layers improves detection quality.

It works best when telemetry is complete and aligned across sources.

## Frequently asked questions

### What is XDR?

XDR, or Extended Detection and Response, is a security approach that collects and correlates telemetry across endpoints, networks, identities, and cloud systems.

### Why is XDR used?

XDR is used to connect signals from different parts of the environment so threats can be detected and investigated more quickly.

### What does XDR collect?

XDR collects telemetry from multiple security and infrastructure layers such as endpoints, network devices, identities, and cloud services.

### How is XDR different from SIEM?

XDR focuses on correlated detection and response across security domains, while SIEM focuses on collecting and analyzing logs and events more broadly.
