# What is Flow Taggerᵀ?

Flow Taggerᵀ is a Trisul Network Analytics feature that classifies and labels network traffic flows based on traffic behavior, applications, protocols, IP ranges, subscriber activity, or custom operational rules.

Instead of treating all traffic flows equally, Flow Taggerᵀ helps network and security teams organize traffic into meaningful categories for easier analysis, monitoring, and investigation.

It improves visibility into:
- application traffic
- suspicious communication
- subscriber behavior
- protocol usage
- business-critical traffic
- operational analytics workflows

## How Flow Taggerᵀ Works

Modern networks generate massive amounts of flow data from:
- routers
- switches
- firewalls
- cloud workloads
- subscriber environments
- application infrastructures

Flow Taggerᵀ analyzes flow metadata and applies labels or tags based on:
- IP addresses
- ports and protocols
- applications
- ASNs
- traffic direction
- behavioral patterns
- custom rules
- security indicators

For example:

1. A traffic flow matches a known streaming application
2. Flow Taggerᵀ assigns an application tag
3. Similar traffic is grouped together
4. Teams analyze the tagged traffic category separately

Traffic can be tagged as:
- business applications
- suspicious traffic
- backup traffic
- cloud services
- VoIP traffic
- subscriber groups
- regional traffic
- security events

## Why Flow Taggerᵀ Matters

Large networks generate traffic from thousands of applications and devices simultaneously.

Without classification, it becomes difficult to:
- identify important traffic
- prioritize investigations
- separate business-critical traffic
- analyze subscriber behavior
- detect suspicious communication
- organize traffic analytics

Flow Taggerᵀ helps teams:
- improve operational visibility
- simplify traffic analysis
- organize monitoring workflows
- identify anomalous traffic
- improve troubleshooting efficiency
- build custom analytics views

It is especially useful in:
- enterprise networks
- ISP environments
- SOC operations
- cloud infrastructures
- multi-tenant deployments

## Common Operational Use Cases

### Application Classification

Group traffic by application or service type.

### Security Monitoring

Tag suspicious or high-risk traffic behavior.

### Subscriber Analytics

Classify traffic by user groups or customer segments.

### Business Traffic Visibility

Separate critical application traffic from non-essential traffic.

### Custom Traffic Analytics

Create tailored traffic categories for operational reporting.

## Flow Taggerᵀ vs Traditional Flow Classification

| Operational Context | Rich | Moderate |
| Traffic Organization | Advanced | Standard |

Flow Taggerᵀ provides more flexible and contextual traffic classification workflows.

## FAQ

### What is Flow Taggerᵀ in Trisul?

Flow Taggerᵀ is a feature that classifies and labels traffic flows based on operational or behavioral criteria.

### Why is Flow Taggerᵀ important?

It helps organize traffic visibility, simplify analytics workflows, and improve operational monitoring.

### What types of traffic can be tagged?

Traffic can be tagged based on applications, protocols, IP ranges, subscriber groups, security behavior, and custom rules.

### How does Flow Taggerᵀ help security monitoring?

It helps identify suspicious traffic, high-risk communication, and anomalous network behavior more quickly.

### Is Flow Taggerᵀ useful for ISPs?

Yes. ISPs can use it for subscriber analytics, traffic categorization, and operational reporting.

### Can Flow Taggerᵀ work with NetFlow and IPFIX?

Yes. Flow Taggerᵀ integrates with flow analytics workflows using NetFlow, IPFIX, and related traffic metadata.
