# What is SD-WAN Monitoring?

SD-WAN monitoring is the process of tracking traffic, path performance, application delivery, and link health across SD-WAN environments.

It helps ensure optimal routing and reliable user experience.

Because automated decisions still need supervision.

Like toddlers and routing engines.

---

## In Simple Terms

Imagine a GPS choosing the best road in real time.

If one road is congested, it reroutes.

That is how SD-WAN works.

It dynamically selects the best network path.

SD-WAN monitoring watches those decisions.

Because “best” changes constantly.

And sometimes badly.

---

## Technical Explanation

SD-WAN monitoring provides visibility into software-controlled WAN paths across multiple transport types.

Common transport links include:

- broadband internet  
- MPLS  
- LTE/5G  
- VPN tunnels  

It typically monitors:

- path latency  
- packet loss  
- jitter  
- application performance  
- path switching behavior  
- link utilization  

SD-WAN is dynamic.

Visibility must be equally dynamic.

Or useless.

---

## How SD-WAN Monitoring Works

1. Edge devices export telemetry  
2. Traffic and path data are collected  
3. Path performance is analyzed  
4. Routing decisions are validated  
5. Alerts and reports are generated  

Dynamic routing.

Continuous measurement.

No rest for operators.

---

## What Does SD-WAN Monitoring Track?

SD-WAN monitoring tracks:

| Metric | Description |
|---|---|
| Path Latency | Delay across available links |
| Packet Loss | Loss per path |
| Jitter | Delay variation |
| Link Utilization | Usage per transport path |
| Application Performance | App behavior over WAN |
| Path Changes | Dynamic route switching events |

More paths.

More metrics.

Progress.
