# What is SD-WAN?

SD-WAN, or Software-Defined Wide Area Network, is a network architecture that uses software control to manage and optimize traffic across multiple wide area links.

---

## How SD-WAN works

SD-WAN devices or controllers choose paths based on policy and measured link conditions. Traffic may be steered across broadband, MPLS, or other transport links.

The aim is to improve application performance and resilience. If one path degrades, traffic can move to a better one.

---

## SD-WAN in operations

SD-WAN is widely used in branch networks and distributed environments. It helps organizations manage connectivity without relying on a single link type.

It also gives operators more visibility into path quality. That makes it easier to troubleshoot and enforce traffic policy.

---

## Common SD-WAN signals

| Signal | Meaning |
|---|---|
| Path quality | Health of each link |
| Steering | Which path traffic used |
| Failover | Switch to backup path |
| Application policy | Rules for traffic handling |

---

## What makes SD-WAN useful

SD-WAN is useful because it combines flexibility with centralized control. That makes it easier to manage multiple sites and changing network conditions.

Its value is highest when application performance matters across remote locations.

## Frequently asked questions

### What is SD-WAN?

SD-WAN, or Software-Defined Wide Area Network, is a network architecture that uses software control to manage and optimize traffic across multiple wide area links.

### Why is SD-WAN used?

SD-WAN is used to improve path selection, resilience, and application performance across wide area connections.

### What does SD-WAN control?

SD-WAN controls traffic routing, path preference, and application-aware policy decisions.

### How is SD-WAN monitored?

SD-WAN is monitored by tracking link quality, path usage, application performance, and failover behavior.
