# What is Hybrid Cloud Analysis?

Hybrid cloud analysis is the process of analyzing traffic, performance, and security behavior across both on-premises and cloud infrastructure.

It provides operational visibility across interconnected environments.

Because workloads move.

Problems follow.

---

## In Simple Terms

Imagine your company stores inventory in your warehouse and in rented storage.

Products move between both.

You need to track:

- movement  
- delays  
- inventory health  

That is hybrid cloud analysis.

Infrastructure lives in multiple places.

Visibility must follow.

Because complexity never travels alone.

---

## Technical Explanation

Hybrid cloud analysis combines telemetry and traffic data from on-premises systems and cloud environments into a unified analytical view.

Common hybrid cloud environments include:

- on-premises data centers  
- public cloud  
- private cloud  
- branch offices  
- edge workloads  

It analyzes:

- flow records  
- traffic paths  
- application dependencies  
- resource usage  
- security events  

Hybrid cloud analysis helps identify:

- bottlenecks  
- latency issues  
- traffic anomalies  
- security threats  
- service dependencies  

Different environments.

Shared consequences.

---

## How Hybrid Cloud Analysis Works

1. Telemetry is collected from on-prem and cloud  
2. Traffic data is aggregated centrally  
3. Data is correlated across environments  
4. Dependencies and anomalies are identified  
5. Insights and alerts are generated  

Many systems.

One analytical picture.

That’s the ambition.
